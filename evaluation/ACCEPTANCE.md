## 本次验证范围

- 27 项自动化测试通过，覆盖页面启动、13 条历史答案切换、结果状态、路径迁移、评测续跑、评分绑定和提交材料链接。
- 在不含 PDF、模型缓存、索引和处理后语料的临时副本中验证历史页面。测试借用本机已有 Python 依赖，不能视为所有操作系统的全新安装测试。
- 187 处答案引用均核对公司、年份、PDF 页码及块 ID，无对应错误；95 个去重证据块已按原回答记录的块 ID 导出。
- README 与逐题查阅页的本地文件链接存在；原五张截图仅将误写的 PNG 扩展名修正为 JPG，内容字节不变，另补三张完整排名截图。
- 不调用真实回答 API，不读取或使用任何密钥。既有真实 API 回答由用户先前生成，此次保持原文。

## 不应隐瞒的限制

Q6/Q7/Q10 仍为部分正确，Q8/Q9 的 top-8 基线存在覆盖不足。这是如实保留的实验结果，不是修改答案来伪造满分。

原有检索评测与回答查询的措辞有差异，不能恢复全部历史请求排名。公开证据为按原回答块 ID 从当前语料回查导出，明确区分于原始 API 请求快照，不补造缺失排名。

本次未重新下载模型、未在老师的实际设备和网络上实测、未进行公网部署。公网可读性须在用户完成 Git 推送后再匿名核对；不能把本地提交当作已经上线。
